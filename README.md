# نُبل للعطور

متجر عطور Static باللغة العربية ويدعم اتجاه RTL، مبني باستخدام HTML وCSS وJavaScript فقط، ومهيأ للنشر على GitHub Pages.

## المزايا

- صفحة رئيسية Premium ومتجاوبة للهاتف والكمبيوتر.
- ستة عطور تجريبية ببيانات مستقلة في `js/products.js`.
- بحث وفلاتر حسب السعر والحجم والنوع والتوفر.
- صفحات تفاصيل المنتجات مع النوتات والتقييم والكمية.
- سلة حقيقية باستخدام `localStorage`: إضافة، حذف، زيادة، تقليل، وحساب التوصيل والإجمالي.
- صفحة Checkout بالدفع عند الاستلام، مع حالة نجاح ورقم طلب تجريبي.
- إعدادات التوصيل قابلة للتعديل في `js/products.js` داخل كائن `delivery`.
- بيانات الدفع الإلكتروني معروضة كخيار مستقبلي دون ربط بوابة حقيقية.
- SEO أساسي: عناوين، أوصاف، Open Graph، وHTML دلالي مع RTL.

## التشغيل محلياً

يمكن فتح `index.html` مباشرة، أو تشغيل خادم Static:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## النشر على GitHub Pages

من إعدادات المستودع: **Settings → Pages → Build and deployment → Deploy from a branch**، اختر فرع `main` ومجلد `/ (root)` ثم اضغط **Save**. الموقع سيُنشر من ملفات `index.html` في جذر المستودع.

## البنية

- `index.html` الصفحة الرئيسية.
- `products.html` الكتالوج والبحث والفلاتر.
- `product.html` تفاصيل المنتج.
- `cart.html` السلة.
- `checkout.html` إتمام الطلب.
- `css/style.css` نظام التصميم المتجاوب.
- `js/products.js` البيانات والأسعار وإعدادات التوصيل.
- `js/app.js` العرض والتفاعل والسلة وCheckout.
